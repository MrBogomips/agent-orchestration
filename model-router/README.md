# model-router

Picks the model and the effort level for sessions and subagents with one written grid, measures how well each
choice worked, and adapts its choices over time.

Status: under construction (0.0.1). See `docs/design/model-router.md` and
`docs/design/model-router-quality-loop.md` for the specification.

## Installation

Plugin only: the router and the quality loop are a mod, and the skills share files through the plugin folder.
Works in any project, with or without `session-hub`.
