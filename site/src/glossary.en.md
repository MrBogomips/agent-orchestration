explaining the system during a knowledge transfer; plain, idiomatic English for a professional software audience;
"you"; never word for word. Keep markup, attributes, class names, ids, URLs, placeholders such as {{img:...}} or
{{link:...}}, and code unchanged.

  costo per successo → cost per success
